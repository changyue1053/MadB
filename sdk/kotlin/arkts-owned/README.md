# CPF Kotlin owned ArkTS backend

C07 implementation scope follows ADR0011 and ADR0013. Kotlin owns the business model, queue, budgets, terminal state and resource ledger. The native executor owns pthread creation/join and the async cleanup hook. The native bootstrap is the only NAPI registrar; main-thread and generated identity checks precede Kotlin initialization.

The source starts from the independently reviewed R6 ordinary/test candidates. The runtime patch derives from public akinterop commit `75ba50c77afda2845a3a6c51cdcddb03d4fd0ab8`; `managed-owned-r6-source.json` lists every original and changed runtime file. Source preparation replays exact hunks and checks the complete result. The per-build identity header is generated after actual KSP Metadata and is excluded from the source patch.

`record-codegen` reads the annotated Kotlin declaration through KSP. It emits the single record codec, typed TypeScript declaration and source-located frontend facts. Ordinary and test source sets are selected before KSP; each invocation preserves stock akinterop generated metadata and declarations. Metadata compiles the matching native helper, cinterop and managed runtime KLIB. Compile and Link read the actual KSP inventory again. No previously built application library is a frontend input.

CPF LLVM, sysroot and platform KLIB stay pinned separately from the formal application's NAPI headers. The exact shared-link correction removes only the known CPF `Scrt1.o` argument from a shared-library link and records the original and corrected argv. One CPF `libc++_shared.so` is delivered with the wrapper and Kotlin provider.

R6 target evidence covers ordinary behavior, recoverable Worker-first rejection, same-env epochs, partial-admission rollback and physical ACK before reuse. It does not cover an observed system env-cleanup callback or every C07 companion control. The successor test source set has 23 actual KSP functions (15 ordinary and eight test functions). Controls retain the same Kotlin business owner and expose real work/terminal, pre-entry delivery, publication staging, clone-error and transfer boundaries. The additional public test facade helpers are generated from their authored source, not copied from a C port. Existing R6 target receipts do not establish these successor controls.

`test-observer` contains generated wrappers for the actual test ELF NAPI import inventory. The generator consumes exact formal SDK declarations and emits same-signature wrappers. The final linked test ELFs must pass complete import/wrapper coverage. The observer records calls before delegation and preserves unknown env validity; logical Runtime closure is not env invalidation. `BootstrapEntries` counts scope constructions, including the nested BootstrapAudit helper scope. It is not a count of independent VM callbacks. Ordinary source selection excludes these inputs and wrapper link flags.

`test-runtime` pins a test-only codec instrumentation delta over the immutable managed R6 patch with exact base/result/patch hashes. The separate memory contract measures canonical UTF8 ledger bytes, actual nativeHeap requested UTF8 storage, successfully cloned precommit publication storage, and actual UTF16 scope array requested bytes. It excludes Kotlin object/String/ByteArray heap, RSS, allocator overhead and unobserved platform storage. UTF16 release is recorded only after memScoped exits. A pure test-only metric CName permits readback after managed metadata teardown, without another registrar or owner. Ordinary uses the original codec and stateless counter hooks.

`contracts` are emitted as original bytes into `generated/contract/test/`; the existing 110-field runtime layout stays at `generated/contract/kotlin-frame-layout.json`. `notices` pins the published runtime POM/KLIB dependency closure, exact source archive attributions and license texts, including transitive serialization; these notices are delivered as HAR members. Build-only dependency notices are not presented as runtime dependencies.
