# C04 输入观察真实执行验收

运行：`.venv/bin/python -m unittest discover -s tests/integration/c04_observations -v`。

复用 C04 DAG 的独立 Python wire fixtures 和真实 helper 进程；不使用 Rust 实现生成期望字节。测试驱动只有显式 `watch` 配置才选择 `execute_graph_observed`，旧 DAG 套件继续使用原入口并验证固定源字节行为。

覆盖已声明源变化、可选路径出现、目录直接成员新增/删除/类型变化、未观察目录和非递归边界、链接与 FIFO/非目录错误、命名子图、预取消、采集与最终复核窗口取消、最终 IO 错误，以及全部节点 owner 的结果移交与目录保留。

文件变化发生在真实首节点返回后的确定窗口。观察取消/错误通过测试专用 workspace 包装器，以已完成节点数区分首次采集和末次复核，不依赖内部读取次数或睡眠排序。真实进程清理核对唯一 marker 与 PID，再恢复测试目录权限；不删除仍被已知存活进程使用的目录。

观察目录只记录直接成员名称和类型；没有声明为文件输入的成员内容变化、未显式观察的子目录变化仍可通过。成功不证明原子快照、完整依赖闭包、可缓存身份或提交资格。
