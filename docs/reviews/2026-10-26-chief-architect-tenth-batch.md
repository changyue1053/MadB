## 范围与输入

实际 MadB 基线为 `3bb06519900a2ab19f0bdd0db11d817160c2482b`，Lab 为 `2d06cbefa0f49187f163ce937c8c3bd01a062eb1`，两仓开工时均干净。逐文件捕获 MadB 1328 项、Lab 523 项字节及模式。实现隔离于 `/private/tmp/madb-chief-round10/repo`；旧 C07 detached worktree 保留。集成前重新核对实际根和原输入，出现后来写入时具体处理，不覆盖他人内容。

I01-R 只扩展已采用的 macOS/aarch64 自然 Rust 值接口配方：原 profile/SDK 字节为权威，在最终根生成 SDK 候选、CMake/Ninja 链接及运行普通 C 消费者。内部 preparation 只编制既有 C04 执行文档，Host 承担执行与提交，不能递归启动另一个 MadB 顶层构建。旧 bootstrap smoke 不代替普通业务输出，初始化成功不授予 IDE、持续重构建或其他目标验收。

E02 补 reader 与 generator 各自的公开会话、独立握手、固定输入输出域及冻结传递；完整组合只提交一次 Source。普通、已选增强与禁用配置的协议/资产证据分别检查，不能从 Source 推导 HAR、Native 或页面运行。替代后端保持独立配置和证据范围，不反向阻断主线。

## 写入与复核

主协调负责共享导出、规范/catalog、集成与证据。初始化实现者写 app initialize、CLI init、Host 执行和既有 C04 单一取消入口接线；资产实现者写新版模板及固定工具记录；原生适配实现者保行为抽取 FrozenPipeline 的内部计划方法并适配原 profile。扩展实现者与 peer 子任务按明确文件分工。独审人员不参与相应实现，不共用生产预期。构建输出分目录，实际产品根仅由主协调集成。

已采用的格式与有限配方足以开工，无新增公开格式决定。模板变更使用新版本，原 0.1.0 字节保留。工具执行依赖从临时调查目录复制到全新本地固定安装，既有安装、SDK、归档和历史候选不覆盖。

## 检查边界

初始化检查真实 build/run、精确工具和 SDK、普通 C 结果、缺项/错身份拒绝、失败和取消保留工程及实际附件；E02 按 catalog 六项验收对账，检查实际双会话、原子提交、坏帧/目录/预算、失败取消和配置隔离。原生进程与取消改动独立复核，最终集成候选另验。

本文初始记录范围及检查条件；实现、冻结候选、实际结果和剩余缺项在完成后追加。当前文字不宣告任何整包通过、远程 CI 通过或发布。

## 实施中发现的具体差异

- 旧原生 preparation 自行生成 profile，不能供新初始化替换已核对原字节。本轮抽取原有上下文投影，安装配方接收原 profile/SDK 并精确比对，工具发现只发生于受信安装准备，执行不从 PATH 回退。
- Python 启动镜像不足以描述运行输入。新增固定运行资源观察，沿已有隔离参数关闭 site 和未锁 pycache，资源记录也进入既有 Source/Build 输入身份；不把只校验 launcher 写成完整准入。
- 开发双会话先前同时取消组合和子控制，不能证明组合取消传播。独立反例只取消组合入口时，子会话仍继续，但最终 Source 发布被正确否决。旧反例保留；修正须复用现有图控制并重新验证活动阶段及阶段间隙。
- 原生适配开发探针使用旧 Host 与新输入，虽然走通 Source/Build/Candidate，其提交身份不属于最终新源码。该开发 Candidate 的正式生产者资格不成立，不进入正式 Lab 通过集合；最终须从新的干净提交同次构建并重新生成。
- 替代后端的普通未知字符串拒绝不等于具体配置对账。当前先核已选来源、依赖/责任和实际缺项；这不要求在 E02 先完成 X 后端实现，也不能据此删去 E02 的声明与拒绝条件。
- [替代配置事实快照](e02-alternative-admission-facts.md)固定 UniFFI-ArkTS、ani-rs 与 KNOI 的官方研究来源，逐项区分上游能力、MadB 适配缺口和拒绝层。KNOI 的研究提交不代表已选择 MadB fork；公共准入反例也不授予这些后端目标认证。
- 初始化独审发现提交取消事实、未完成进程持有者、结果保存尾部证据和冻结工具漂移分类四处缺口。修复沿既有取消/结果契约，不以晚到取消标志重分类普通 IO 失败；已保存的原始结果不覆写，尾部失败使用重新核对字节的新证据根。
- 两组件流程在复用图级持有者后还需保留异常展开保障：外层捕获某步骤 panic 不能使后续步骤覆盖旧活动进程。进入步骤前记录未完成状态，正常完成才依据实际结果更新；活动阶段的作用域持有者在展开时取消旧子控制，后续步骤保持拒绝。
- 实测工具执行还读取 Rust 的 libLLVM/librustc_driver，并由 Clang 选择固定 ld。它们补入私有执行资源的字节与别名记录，沿同一 Source/Build 输入身份核对；不改原 SDK/profile，不把有限资源核验称为整个操作系统或任意编译器沙箱。
