# Swift 生产基线与全套文档复核

日期：2026-10-25。设计基线：0.9。观察基于 MadB `22ab5726d7bb001f1cb39d66a43377bb6be64abf` 及开始本次整合时的工作区；保留既有未提交内容。这是 L01 的文档设计子范围，不是 L01 或 Swift SDK 的完成证明。

## 范围与设计结论

本次将 Swift 调研和裁定整理为 [ADR-0014](../adr/0014-swift-production-baseline.md)，十二项讨论索引映射已有规范和工作包。检查覆盖全套文档，只有发现缺口的现行规范和投影需要修改；不增加包、核心层、门禁编号或工具依赖。

- 复用 Kotlin/Native + SKIE、UniFFI、Clang importer 及明确的 C/C++ 配方；版本与能力分别以锁及 profile 为准。
- 从固定业务样例补齐声明驱动的必要 Facade，保留可复用手写运行原语；普通 API 独立可用，避免复制所有后端模型或新增重复 IDL。
- 明确并发、资源、取消、状态/事件与宿主回调协议；不同后端复用既有 DEC 与验收要求，不建立另一套 Swift 资源内核。
- 公开 Swift 消费优先采用必要 Swift 源码与原生 XCFramework 的 SwiftPM 配方；正常 IDE 构建、身份装配、第二业务模块、原候选发布下载分别验证。
- 普通消费者、SDK 作者和扩展作者各自承担最小必要知识；候选工具和增强不成为无条件依赖。具体增强启动时间由项目所有者决定。

现有 C06 证据仅覆盖固定 SampleEngine 的选定 macOS Arm64 配置；不能据此承诺 iOS、任意业务生成、完整 XCFramework 或公开发布。旧 mad 与 MadDemo 只提供问题和机制案例，不作为 MadB 认证或迁移任务。

## 一致性与降噪

ADR 只记录取舍和映射；协议放回所属架构规范，使用流程、验收实例和进度各有一个权威入口。首页和视图说明将“Swift 默认 SKIE”限定为 Kotlin/Native → Swift，避免泛化到 Rust 或 C/C++。初始化产品页改为目标能力表述，避免误认为已有可交付 init 命令。

历史研究、历史验证数据、公共格式、工具锁及 Lab 固定规范副本不增加或变更认证结论。旧架构简化报告第 51–94 行有遗留行首 `+` 的渲染瑕疵；其原始字节已被历史检查摘要固定，因此保留原件，不修改旧摘要来补作新验证。现行阅读入口使用本次报告与权威规范。生成 HTML 只从目录和模板再生。全套检查、任务治理字段保护及实际验证范围在整合完成后记录如下。
