## 语义复核

- 覆盖 Swift/Kotlin/ArkTS/Rust/C/C++、新语言、SDK 体验、构建分发和宿主服务；不要求所有路线使用同一 FFI 或运行时。
- 设计端口和候选工具不宣称已实现；当前清单 v1 的说明文本不充当可执行约束，格式缺口必须经过受控演进。
- 同一逻辑阶段唯一 owner 与合法多订阅分别表达；构建扩展取消与 SDK 运行时关闭分别验收。
- 多组件逐项成功不等于组合通过；固定中间产物、输出所有权、单一物理装配、完整候选和独立消费都保留。
- 通用运行时可手写；新业务声明的受支持子集和生成能力独立证明。
- 任务数量保持 41，主线路线保持 16；scope、phase、start_phase、depends_on、status、verification、owner、日期和 evidence 与写回基线相同。
- 没有新增开工日、安装依赖、触发远端 CI、提交 Git 或发布制品。现有授权任务继续按其原范围推进。
