# 路线专题质量修订

日期：2026-10-24。设计基线仍为 0.7；以既有 Kotlin/Native ↔ Swift 专题作为内容深度与视觉语言的参照，重做新增七组边界与扩展专题，共八页。参考页及主线目录、计划、认证保持不变。

上一版覆盖了路线，但固定十二槽位和单路径高亮压缩了真实架构关系；文字清单没有替代完整架构图、时序、模型和所有权表达。本轮针对这些差异修订，不能仅以文件数量和脚本通过作为页面质量结论。

| 维度 | 修订 |
|---|---|
| 阅读结构 | 与参考页一致：全景、构建、时序、类型错误、生命周期、模块原则、验收、依据 |
| 架构图 | 移除固定十二槽位；按具体工具链与运行机制设置节点，区分构建/准备期与运行/执行期，默认展示全部具名关系 |
| 图形语言 | 复用参考页的色彩、分区、节点责任条、具名箭头、说明面板、章节导航与打印风格；业务、MadB、上游、消费端分色 |
| 交互 | 全景链路筛选与消息场景切换分离；节点详情分别列职责、输出和约束 |
| 运行机制 | 每配置独立显示调用、反向、关闭场景；四条生命线、请求、回应、投递和本地处理有区别 |
| 类型与示例 | 增加值、对象身份、错误的三类路径；补充协议伪代码及其适用边界，不冒充已实现 API |
| 内存并发 | 增加 owner 树、Open/Closing/Closed/Invalid 规则、借用窗口、工作/等待/回调区别及失败交错 |
| 模块与原则 | 将具体配置映射到 Reader、rules/plan、Generator、SDK、Toolchain、Artifact/Verifier；解释职责与禁止越界的内容 |
| 验收 | 风险、处理协议、具体反例和相关任务同表；需要精确配置证据，不从共享任务推导认证 |
| 扩展差异 | 语言后端、工程服务、诊断增强分类。远程存储突出宿主校验/提交；IDE 明确最终路径提交后再构建；插桩保留未插桩对照 |

特别校正：ANI 不复用 Node-API 的引用与线程协议；Dart 同步探针不绘制宿主回调链，反向场景展示能力拒绝；Swift C++ 直接调用不假定可捕获 C++ 异常。CXX 的 Result 与 panic 边界、Kotlin StableRef 和 pinning 规则按官方资料核对。

机制依据：[Swift C++ 约束](https://www.swift.org/documentation/cxx-interop/status/)、[CXX Result](https://cxx.rs/binding/result.html)、[Kotlin C interop](https://kotlinlang.org/docs/native-c-interop.html)。各专题保留原有规范与上游来源入口。

## 检查与限制

结果见[验证记录](route-depth-validation.json)。检查覆盖 29 个配置的拓扑、节点边界和相互重叠、连线引用、类型路径、时序角色、代码换行、任务关联、静态 HTML/链接/脚本及生成一致性。共 511 个机制节点、596 条架构关系；这些数量用于核对覆盖，不作为质量评分。

隔离的 DOM 形状单元环境执行了配置切换、173 次链路筛选、87 个时序场景、3050 次节点键盘选择、扩展分类、深链接与主题。该环境不是浏览器，不能验证实际字体、排版、窄屏滚动、完整可访问性或真实浏览器行为。

浏览器工具的本地 file:// 访问仍受 URL 策略限制，本轮没有绕过策略；实际视觉与浏览器交互复验未完成。内容重构、几何检查和脚本通过不能代替截图与实际操作确认。未执行跨语言 SDK 或设备测试。

## 展示数据维护

`madb.route-detail-view/2` 仅为可视化数据格式，不改变产品 IR。`detail.graph` 为实际节点与连线的唯一来源；`detail.sequences` 为消息时序来源。已删除旧的固定槽位节点与不再使用的路径数组，避免两套拓扑相互漂移。生成器同时检查描述数据与目录身份。
