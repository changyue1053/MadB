# C04 输入观察与图执行复核

任务：C04 / DEC-06、CRIT-10 的输入观察子范围。依据设计 0.9、架构 02/07、模块/整洁代码/质量规范；基线 `e960a2fd7210a0ab337f2c7e3235acd897d8e71d`，PR #8 已通过两组 CI、未合并。分支 `codex/c04-input-observations`。

范围：app 的受检观察集合及捕获/复核，host 的描述符相对存在性/目录直接成员读取，DAG 的显式观察入口，端口与真实进程回归，规范/计划及生成 HTML。不实现编译器 depfile 或完整依赖发现、重绑定、缓存、输出事务/CAS、持久化观察格式、E02、正式 build/generate CLI；C04 仍在进行中。

实施决定：

- 原 execute_graph 保持固定字节执行语义；新增 execute_graph_observed 显式要求观察前后未变，不能静默更改旧调用者对源树后续变化的约定。
- InputWatchSet 由调用者显式声明 absent 路径和目录路径。目录观察仅完整直接成员的名称与 File/Directory 类型，不递归、不等价于追踪成员内容。已声明外部文件沿用同一 FrozenInputs 根快照，最终复核真实字节；不另外复制整份源数据。
- ObserveWorkspace 端口归 app，host 实现有界、无链接跟随的读取。exists 的最后一段通过不跟随链接的元数据判断，dangling symlink 也算存在；中间链接、权限及非目录错误不能当成缺失。列目录拒绝链接/特殊节点、不支持名称及硬链接普通文件，不静默过滤。
- 观察结构在 IO 前检查：路径 ASCII、32 层、重复、目录段大小写别名、缺失路径与已声明文件/目录的矛盾。目录和其合法后代可以同时声明；absent 父路径不能同时包含声明存在的目录/文件。至多 4096 个 absent、256 个目录，合计直接成员不超过 8192、成员名称合计不超过 2 MiB；宿主读取与 app 端口复核都执行界限。
- 同一 GraphControl gate 内先捕获观察、固定源文件并复核，再执行节点；正常完成后、最终接受前，再复核所有源文件和观察。取消覆盖所有新增窗口，无锁执行 IO；错误/取消保留已执行节点 owner 和原始节点执行观察，不公开图结果集。同步文件 IO 不承诺可中断。
- 捕获集合必须内部一致：目录完整成员不能遗漏已声明存在后代所要求的直接子项；实际成员与缺失声明、根文件或其他观察发生大小写/类型矛盾时拒绝。声明前缀最多 8192，合并实际成员的前缀最多 16384；不声称捕获同时发生。
- 只观察实际选中图的 external source 文件；额外 watch 集合完全显式，不自动从所有配方猜测。临时运行目录应放在所观察源目录之外；本轮不自动排除新增输出目录。
- 目录枚举加复读不是原子文件系统快照，不能发现所有 ABA 变化。宿主工作区根按打开时的目录描述符固定，调用方负责稳定根路径。成功只说明已声明条件在检查点相符；不证明完整读取集合、确定性缓存、批次来源或提交资格，后续提交窗口仍须再次复核。
- 不新增 schema、摘要域或可缓存标记，不把 watch 偷塞入 extensions。工具、argv、显式环境及 profile 身份继续使用现有绑定，未声明环境与传递依赖仍由后续 reader/toolchain 收敛。

验收：正常观察执行；原入口行为保持；新增/删除/改类型目录成员、可选文件出现、已声明内容变化拒收，声明范围外内容改变不误判；命名子图范围、无IO结构拒绝、预算、别名、链接/特殊文件、目录错误不伪装缺失；预取消/捕获期间/最终复核期间取消及owner无结果泄漏；本地完整门禁、独立审查和最终head Linux CI。

- host 新增元数据存在检查和有界直接目录枚举，不使用普通 exists() 吞掉权限/类型错误；末段链接判存在，中段链接和目录成员链接拒绝。
