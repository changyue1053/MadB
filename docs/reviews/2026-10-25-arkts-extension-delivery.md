## 首片实现

新增 [StateObservation 与 ArkUIStateModel](../../sdk/arkts/observation/README.md)，直接复用 C07 的 Engine/Snapshot/Subscription，普通与 UI 入口分开：

- 构造和 getter 不注册；一个控制器最多持有一个订阅，重复注册明确拒绝。
- requestStop 同步阻止本地新投递，再调用源停止；close 合并并发/重入等待，成功后才允许重启，失败保留原订阅和错误供显式重试。
- attachment 身份隔离旧代回调；页面不关闭共享 Engine；没有新增 Native owner、定时器、队列或第二份业务状态权威。
- ArkUI V2 仅观察 snapshot 替换；phase/closeFailure 是普通只读查询。同步注册成功后才发布暂存快照，注册失败保留原快照，发布后清除暂存引用。

独立审查发现并修复同步注册先交付后失败会污染旧快照的问题，补充回归；同时消除监听闭包对暂存快照的额外长期持有。另补非法 listener 的注册前拒绝。最终独立审查无首片阻断项。计划审查还修正 E05“独立后端”与 I05“特殊交付”可能造成的文字验收环，修后依赖和范围均复核通过。 检查器独立审查还发现目录大小写别名绕过保护、非法 inventory 缺失败记录及编译失败缺输入摘要；现按文件系统身份拒绝受保护目录、统一记录失败并在执行前保存输入，相关负例与四项正式构建重跑通过。

当前交付是可复制到既有生成 Facade 旁的可选源码，尚未自动加入 MadB 生成或发行配方；没有给出新的正式候选身份。固定 C07 Snapshot 适配不证明任意业务声明生成。声明、包、消费者的实际编译与 Native/UI 运行证据分开保存。
