    每一层，只承担自己的责任

    生成、协议执行和业务语义分别设计；不因包装更简洁而扩大安全承诺。

    01 / 可机械推导工具生成

    参数与返回值转换、有限 DTO 投影、释放接线、回调包装、来源映射、构建配置。前提是契约完整、后端支持。

    02 / 必须明确实现作者和平台适配

    领域能力、算法、unsafe 前提、自定义同步、无法推导的关闭和停止能力。通用工具检查可检查的条件。

    03 / 普通 SDK 使用业务开发者

    调用方法、观察状态、接入页面生命周期、关闭自己拥有的资源。仍需理解受理、完成和取消的业务效果。

    两个工程，一套明确的源码边界

    目录从模块规范和 Lab 规范直接生成。六个核心 crate、实际适配器和语言原生构建分别登记；目标结构不表示产品代码已经存在。
