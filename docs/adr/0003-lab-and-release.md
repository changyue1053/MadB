# ADR 0003 独立 Lab 与制品验证

状态：本轮设计采用。日期：2026-10-23。

## 背景

代码生成测试可能与生成器共享错误假设。开发目录中运行成功，也可能依赖未打包文件、缓存、私有依赖或不匹配的二进制。

## 决策

MadB 保留核心与适配器单元测试；MadB-Lab 独立维护通用 fixture、平台消费工程、场景、独立预期和发布验收。Lab 通过公开工具接口和版本化候选包测试，不导入 MadB 私有实现。

候选包在验证前冻结摘要。报告关联包、工具链、profile、Lab revision 和案例。通过后发布相同内容，发布过程不再重建后沿用旧结果。

## 备选方案与影响

全部测试放在工具仓更方便联调，但容易绕开真实消费流程。独立工程增加两个 revision 和协议兼容的管理成本，因此共享的是稳定 schema 和问题编号，而非内部实现。

Lab 内可以提供针对新功能的开发模式；发布资格只采信标准候选消费路径。测试预期来自契约，不能调用生产生成器计算正确答案。

## 验证

删除发布包中的必要文件、替换不匹配原生库、改变工具锁、打断资源停止协议时，对应测试和门禁必须失败。环境缺失与跳过不得升级为通过。
