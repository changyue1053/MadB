# MadB 术语表

| 术语 | 本项目含义 |
|---|---|
| 边界 | 一个公开能力从某运行时进入另一运行时的接口与行为关系 |
| 路线 Route | 提供方、消费方、方向与桥接机制的组合；不包含已认证的暗示 |
| 边界配置 boundary profile | 一条路线加确定的运行时、方向、目标、功能、工具版本、交付形态和构建约束；供构建及认证使用 |
| 模板配置 template profile | 初始化工程的模块、UI、目标和构建组合；引用一个或多个边界配置 |
| 路线别名 | 目录中的稳定大写 ID；通过 routes.json 显式映射到扩展协议使用的命名空间 ID |
| 契约 | 调用者和实现者必须共同遵守的类型、行为和资源约定 |
| 权威源 | 某类信息被维护和修改的唯一来源 |
| IR | 工具用于分析和生成的内部结构化模型 |
| ABI | 二进制层面的布局、调用和符号约定 |
| Facade | 面向使用者的轻量外观，隐藏不必要的桥接细节 |
| 快照 | 在声明的隔离条件下读取并具有约定独立性的数据 |
| owner | 承担关闭决策或资源回收责任的对象/作用域 |
| 借用 | 在限定寿命和访问权限下临时使用资源 |
| 准入许可 | 在关闭与调用竞争时证明一次操作可以使用资源 |
| 排水 drain | 等待已获准工作或回调完成并释放相关持有 |
| 取消请求 | 表达调用方不再等待或请求底层停止，效果取决于契约 |
| 停止确认 | 规定的工作、观察或资源已经达到停止后条件 |
| 受理 | 请求已进入业务处理责任范围，不一定完成副作用 |
| 声明能力 | 后端声称可以处理的特征，不等于已有运行证据 |
| 认证能力 | 某个具体版本与目标通过规定验收的能力 |
| 证据 | 可关联到输入、目标、制品和测试的实际验证结果 |
| 不利条件用例 | 非法输入、故障、竞态等需要被拒绝或安全处理的场景 |
| 完整版本 | 满足当前公开范围和所有必需验收项的版本 |
| CPF 工具链 | 鸿蒙 Kotlin/KMP 及可选 CMP 的社区工具链与配套依赖；不等于一个调用桥 |
| akinterop | CPF 默认路线使用的 Kotlin/Native 与 ArkTS 互操作组件；与工具链分别锁定 |
| Maven 坐标 GAV | group、artifact、version 构成的制品身份；官方与 CPF 首版使用独立坐标 |
| 根 publication | KMP 公共依赖入口及其引用各平台制品的 metadata；不是某一个目标的 klib |
| 模板补丁身份 | 生成器源码提交、补丁及模板摘要；runtime 版本相同不代表生成代码相同 |
| 交付票据 | 保活排队载荷并在目标执行器中认领投递资格的协议对象；不是原生工作计数 |
| 终态认领 | 决定一次调用只提交一个完成结果；不等于调用方已经拿到资源 |
| 描述性配置 | HTML 中解释机制的配置条目；不等于已解析、已锁定、已认证的 boundary profile |
