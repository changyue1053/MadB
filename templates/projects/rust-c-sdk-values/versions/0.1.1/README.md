# Rust/C values template 0.1.1

This version extends the finite initialized project assets for the checked
macOS values recipe. It keeps the ordinary Rust declarations and ordinary C
helper; CMake now validates candidate paths and records the exact library
directory as the consumer build RPATH. The manifest binds CMake 4.4.4 and Ninja
1.13.2 executable identities for build/run requirements, together with the ten
native tools already bound by the profile and SDK. CMake and Ninja remain
project build requirements; they are not added to the native boundary SDK.
The profile and SDK bind the actual 0.1.0 helper images used in the installed
recipe, without adding the running host image to its own input digest.

`source/` is authoritative. `package.tar` and `identity.json` are generated by
`python3 scripts/build_init_template.py`; `--check` verifies both this version
and the preserved 0.1.0 package. The previous version remains at the parent
template root with its original bytes and catalog identity. Actual template
execution is admitted separately by the installed catalog and recipe, and
must bind the final profile/SDK inputs and observed tools before use.
